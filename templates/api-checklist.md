# Elenco di controllo del test API

- [ ] Contratto, metodi, percorsi, codici di stato, intestazioni e tipi di media
- [ ] Campi obbligatori, facoltativi, nulli, predefiniti e sconosciuti
- [ ] Richieste valide, non valide, limite, duplicate e fuori ordine
-[] Autenticazione, autorizzazione, isolamento del tenant e output sensibile
- [ ] Impaginazione, filtro, ordinamento, impostazioni locali, fuso orario e set di dati di grandi dimensioni
- [ ] Idempotenza, concorrenza, timeout, nuovi tentativi e limitazione della velocità
- [ ] Formato dell'errore, identificatori di correlazione, log e osservabilità
- [ ] Compatibilità, deprecazione, ipotesi del consumatore e controllo delle versioni
- [ ] Errore della dipendenza e comportamento di ripristino
- [ ] Pulizia dei dati e prove a tutela della privacy

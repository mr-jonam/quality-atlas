# First worksheet: release evidence / Primo template: evidenze di rilascio

## English

Fictional, synthetic example for the [release-readiness worksheet](../templates/release-readiness.md). No real product was reviewed.

| Field | Example |
| --- | --- |
| Change | A demonstration shop changes its receipt email. |
| Intended outcome | A completed purchase receives one receipt with the correct total. |
| Known fact | In this fictional exercise, one happy-path check is reported as passing. |
| Missing evidence | Retry and duplicate-notification behaviour have not been demonstrated. |
| Decision owner | The role accountable for accepting purchase communications; not yet assigned. |
| Next question | Who will review evidence about duplicate receipts before deciding? |
| Decision | Open. This example supplies no approval. |

Open the worksheet, fill only facts you can substantiate, and mark missing fields as unknown. Compare your own evidence and owner fields with this example. A second reviewer should be able to distinguish a reported result, a gap and an undecided action.

## Italiano

Esempio inventato e sintetico per il [template di readiness](../templates/release-readiness.md). Nessun prodotto reale è stato verificato.

| Campo | Esempio |
| --- | --- |
| Modifica | Un negozio dimostrativo modifica l'email di ricevuta. |
| Risultato atteso | Un acquisto completato riceve una ricevuta con il totale corretto. |
| Fatto noto | Nell'esercizio fittizio, un controllo sul percorso principale è riportato come superato. |
| Evidenza mancante | Non è stato dimostrato il comportamento con retry e notifiche duplicate. |
| Responsabile della decisione | Il ruolo che accetta le comunicazioni d'acquisto; ancora da assegnare. |
| Prossima domanda | Chi esaminerà le evidenze sulle ricevute duplicate prima di decidere? |
| Decisione | Aperta. L'esempio non fornisce approvazione. |

Apri il template, inserisci solo fatti dimostrabili e indica come sconosciuti i campi mancanti. Confronta evidenze e responsabilità con l'esempio. Un secondo lettore dovrebbe distinguere un risultato riportato, una lacuna e un'azione ancora da decidere.

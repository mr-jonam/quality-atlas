# Erste 30 Tage in einer QA-Rolle


### Tage 1–10: verstehen

- Lernen Sie die Produktergebnisse, Benutzergruppen, kritischen Reisen und den Wortschatz kennen.
- Kartenumgebungen, Lieferfluss, Datenquellen, Supportrichtlinien und bekannte Risiken.
- Führen Sie das Produkt aus und beobachten Sie eine Änderung von der Idee bis zur Bereitstellung.
- Sehen Sie sich eine kleine Auswahl aktueller Mängel und Vorfälle an.

### Tage 11–20: beitragen

- Koordinierung von Risikoanalyse, Testdesign und einer Erkundungssitzung.
- Führen Sie die bestehende Feedback-Pipeline aus und erläutern Sie sie.
- Verbessern Sie eine unklare Notiz, eine unzuverlässige Prüfung oder eine Diagnoselücke.
- Teilen Sie Fragen und Annahmen frühzeitig mit.

### Tage 21–30: ein kleines Ergebnis erzielen

- Lead-Test für eine begrenzte Änderung.
- Deckung und Restrisiko kommunizieren.
- Schlagen Sie eine messbare Verbesserung der Feedback-Geschwindigkeit oder -Qualität vor.
- Vereinbaren Sie das nächste Lernziel mit einem Kollegen oder Lead.

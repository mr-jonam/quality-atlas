# Sesión de prueba exploratoria


1. **Marco**: elija un riesgo, característica o pregunta y escriba una carta de una frase.
2. **Timebox**: normalmente entre 30 y 90 minutos; seleccione un período de tiempo más corto para una pregunta específica.
3. **Preparar**: entorno, datos, oráculos, herramientas y limitaciones conocidas.
4. **Explorar**: observación alternativa, modelado, experimentos y toma de notas.
5. **Variar**: datos, secuencia, temporización, permisos, interrupciones y dependencias.
6. **Informe**: resume la cobertura, los hallazgos, la evidencia, las preguntas sin respuesta y los seguimientos.

Mantenga notas ligeras: marca de tiempo, acción, observación, idea, problema, pregunta. Distinguir un problema confirmado de una pista de investigación.

# Séance de tests exploratoires


1. **Frame** : choisissez un risque, une fonctionnalité ou une question et rédigez une charte d'une phrase.
2. **Timebox** : généralement 30 à 90 minutes ; sélectionnez une période plus courte pour une question précise.
3. **Préparer** : environnement, données, oracles, outils et contraintes connues.
4. **Explorer** : observation alternative, modélisation, expériences et prise de notes.
5. **Varier** : données, séquence, timing, autorisations, interruptions et dépendances.
6. **Débrief** : résumez la couverture, les conclusions, les preuves, les questions sans réponse et les suivis.

Gardez les notes légères : horodatage, action, observation, idée, problème, question. Distinguer un problème confirmé d’une piste d’enquête.

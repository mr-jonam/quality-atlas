# Mentalidad de control de calidad


El aseguramiento de la calidad mejora el sistema que crea software; Las pruebas evalúan un producto o una idea para conocer los riesgos relacionados con la calidad. Se superponen pero no son sinónimos.

Hábitos útiles:

- Pregunte qué resultado importa y quién podría resultar perjudicado por el fracaso.
- Convertir las suposiciones en ejemplos que puedan discutirse o comprobarse.
- Busque comentarios rápidos al nivel útil más económico.
- Observar el producto, el sistema de entrega y el entorno operativo.
- Hacer visible la incertidumbre en lugar de forzar una respuesta falsa de aprobado o reprobado.
- El estudio evitó los defectos sin culpar a los individuos.

### Preguntas para hacer temprano

1. ¿Qué problema pretende resolver este cambio?
2. ¿Qué no debe suceder nunca?
3. ¿Qué usuarios, datos, integraciones y entornos se ven afectados?
4. ¿Cómo observaremos el éxito y el fracaso?
5. ¿Se puede liberar, limitar y revertir el cambio de forma segura?

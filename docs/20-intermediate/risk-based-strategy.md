# Risikobasierte Teststrategie


Eine Teststrategie erklärt, wie das Team innerhalb realer Einschränkungen nützliche Erkenntnisse über die wichtigsten Risiken erhält.

### Erstellen Sie die Strategie

1. Identifizieren Sie Qualitätsrisiken als unsichere Ereignisse mit Konsequenzen.
2. Schätzen Sie die Auswirkungen und die Wahrscheinlichkeit mithilfe einfacher relativer Skalen ab.
3. Fügen Sie Modifikatoren hinzu: Erkennbarkeit, Exposition, Reversibilität, Neuheit und Abhängigkeitstiefe.
4. Wählen Sie Präventions-, Überprüfungs-, Test-, Überwachungs- und Wiederherstellungsaktivitäten aus.
5. Definieren Sie Umgebungen, Daten, Verantwortlichkeiten, Eintrittssignale und Austrittsnachweise.
6. Bewerten Sie neu, wenn sich Umfang, Architektur, Vorfälle oder Nutzung ändern.

Die Abdeckung ist mehrdimensional: Anforderungen, Risiken, Code, Schnittstellen, Daten, Plattformen, Benutzer und Betriebsszenarien. Kein einzelner Prozentsatz repräsentiert alles.

### Restrisiko kommunizieren

Geben Sie an, was untersucht wurde und was nicht, wichtige Ergebnisse, Vertrauensgrenzen, aktive Abhilfemaßnahmen und wer das verbleibende Risiko übernimmt. Eine Freigabeentscheidung ist eine Geschäftsentscheidung, die auf Qualitätsnachweisen basiert.

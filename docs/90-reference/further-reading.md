# Ulteriori letture

Questi collegamenti portano a fonti pubbliche autorevoli. Gli standard e le linee guida si evolvono; verificare la versione corrente prima di utilizzarli per la conformità o la certificazione.


- [ISTQB Certified Tester Foundation Level](https://www.istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/): vocabolario di test strutturato e programma di base.
- [Guida ai test di sicurezza Web OWASP](https://owasp.org/www-project-web-security-testing-guide/): guida ai test di sicurezza Web.
- [OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/): requisiti di sicurezza dell'applicazione e riferimento alla verifica.
- [Linee guida W3C per l'accessibilità dei contenuti Web](https://www.w3.org/WAI/standards-guidelines/wcag/): standard di accessibilità e risorse di supporto.
- [DORA search](https://dora.dev/research/): ricerca sulla distribuzione del software e sulle prestazioni operative.
- [Google Testing Blog](https://testing.googleblog.com/): articoli pubblici sulle pratiche di testing ingegneristico.
- [Martin Fowler: Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html): una discussione pratica sui test automatizzati a più livelli.
- [RFC Editor](https://www.rfc-editor.org/): specifiche del protocollo Internet primario.
- [roadmap.sh QA Engineer](https://roadmap.sh/qa): una panoramica visiva gestita dalla comunità degli argomenti di apprendimento QA più comuni e delle categorie di strumenti. Quality Atlas lo utilizza come input, non come un curriculum approvato o esaustivo.

Nessuna fonte esterna approva o è affiliata a questo repository.

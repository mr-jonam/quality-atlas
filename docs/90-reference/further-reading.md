# Lectures complémentaires

Ces liens mènent à des sources publiques faisant autorité. Les normes et les directives évoluent ; vérifiez la version actuelle avant de les utiliser à des fins de conformité ou de certification.


- [ISTQB Certified Tester Foundation Level](https://www.istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/) : vocabulaire de tests structurés et programme de base.
-[OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) : conseils pour les tests de sécurité Web.
-[OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/) : exigences de sécurité des applications et référence de vérification.
- [W3C Web Content Accessibility Directives](https://www.w3.org/WAI/standards-guidelines/wcag/) : norme d'accessibilité et ressources de support.
- [DORA search](https://dora.dev/research/) : recherche sur la livraison de logiciels et les performances opérationnelles.
- [Google Testing Blog](https://testing.googleblog.com/) : articles publics sur les pratiques d'ingénierie des tests.
- [Martin Fowler : Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) : une discussion pratique sur les tests automatisés en couches.
- [RFC Editor](https://www.rfc-editor.org/) : spécifications principales du protocole Internet.
- [roadmap.sh QA Engineer](https://roadmap.sh/qa) : un aperçu visuel maintenu par la communauté des sujets d'apprentissage et des catégories d'outils d'assurance qualité les plus fréquemment rencontrés. Quality Atlas l'utilise comme une entrée, et non comme un programme approuvé ou exhaustif.

Aucune source externe n'approuve ou n'est affiliée à ce référentiel.

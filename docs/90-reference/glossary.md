# Glossario QA

| Termine | Definizione |
|---|---|
| Acceptance criterion | Condizione verificabile associata a un bisogno o elemento. |
| Check | Valutazione rispetto a un'aspettativa esplicita. |
| Coverage | Grado con cui un modello, rischio o elemento è stato esaminato. |
| Defect | Imperfezione che può impedire al prodotto di soddisfare un bisogno. |
| Error | Azione umana che produce un risultato errato. |
| Failure | Deviazione osservabile durante l'esecuzione. |
| Flaky test | Test automatico con esiti incoerenti senza modifica rilevante del prodotto. |
| Oracle | Fonte usata per riconoscere un risultato atteso o problematico. |
| Quality risk | Possibilità di un problema di qualità e delle sue conseguenze. |
| Regression | Impatto negativo involontario causato da una modifica. |
| Severity | Livello di impatto causato da un problema. |
| Priority | Urgenza relativa assegnata a un'attività. |
| Test basis | Informazioni da cui derivare test, come bisogni, rischi, codice o modelli. |
| Test charter | Missione e confini di una sessione esplorativa. |
| Testability | Grado con cui un sistema supporta una valutazione efficiente. |


I termini possono avere definizioni più formali in standard e syllabus. Usa il vocabolario concordato nel contesto e rendi esplicite le ambiguità.

# QA Glossary

| Term | Definition |
|---|---|
| Acceptance criterion | Testable condition associated with a need or item. |
| Check | Evaluation against an explicit expectation. |
| Coverage | Degree to which a chosen model, risk, or element has been examined. |
| Defect | Flaw that may cause a product to fail to meet a need or expectation. |
| Error | Human action that produces an incorrect result. |
| Failure | Observable deviation during operation. |
| Flaky test | Automated test with inconsistent outcomes without a relevant product change. |
| Oracle | Source used to recognize an expected or problematic result. |
| Quality risk | Possibility of a quality-related problem and its consequences. |
| Regression | Unintended negative impact caused by a change. |
| Severity | Degree of impact caused by a problem. |
| Priority | Relative urgency assigned to work. |
| Test basis | Information used to derive tests, such as needs, risks, code, or models. |
| Test charter | Mission and boundaries for an exploratory testing session. |
| Testability | Degree to which a system supports efficient evaluation. |

Terms may have more formal definitions in standards and certification syllabi. Use the vocabulary agreed by your context and make ambiguity explicit.

# Contribuer

Les contributions qui améliorent la clarté, l’exactitude, l’accessibilité ou la parité linguistique sont les bienvenues.

## Règles de contenu

- Gardez chaque note utile sans contexte spécifique à l'organisation.
- Rédiger tous les contenus pédagogiques en français. Gardez le sens aligné avec la branche principale.
- Utilisez des exemples fictifs et génériques et des exemples de données non sensibles.
- N'ajoutez jamais de noms, d'informations client, d'informations d'identification, d'URL privées, d'architecture interne ou de playbooks propriétaires.
- Préférez les explications concises, les résultats observables et les listes de contrôle pratiques.
- Citer des sources publiques faisant autorité lorsqu'une affirmation dépend d'une pratique standard ou en évolution.
- Ajoutez le frontmatter YAML requis et mettez à jour « mis à jour » en utilisant « AAAA-MM-JJ ».

## Flux de travail

1. Créez ou modifiez une note ciblée.
2. Liez-le à partir de la carte de contenu la plus proche.
3. Exécutez `npm run check`.
4. Examinez la différence pour les données sensibles accidentelles.
5. Soumettez une pull request expliquant le résultat d'apprentissage.

En contribuant, vous acceptez que la documentation soit sous licence CC BY 4.0 et le code sous MIT, comme décrit dans « LICENCE ».
